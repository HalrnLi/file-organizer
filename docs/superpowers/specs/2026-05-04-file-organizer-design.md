# File Organizer — 设计文档

> 快速文件整理工具，Windows 桌面端，C# .NET WinForms 实现

## 一、技术栈

| 层面 | 选型 |
|------|------|
| 语言 | C# |
| 框架 | .NET 8+ WinForms |
| 发布 | AOT 单文件 exe |
| 配置 | JSON（rules.json, settings.json） |

### 模块职责

- **悬浮窗**（FloatingWindow） — 半透明小窗口，可拖拽位置，接收文件拖放
- **右键菜单**（ShellExtension） — 通过注册表注册，选中文件后出现 "整理(File Organizer)"，启动程序并传参
- **整理弹窗**（OrganizeDialog） — 核心交互窗口：显示源文件、可编辑文件名、标签列表单选
- **规则管理**（RuleManagerForm） — 标签-路径映射的增删改查
- **设置窗口**（SettingsForm） — 全局偏好配置
- **配置管理器**（ConfigManager） — 读取/写入 JSON 配置，内存缓存，文件变更检测
- **文件移动器**（FileMover） — 执行实际文件操作，处理冲突和错误
- **单实例守卫**（SingleInstance） — 确保只有一个进程实例

## 三、UI/UX 设计

### 3.1 悬浮窗

- 尺寸 80×80px，正常态 50% 透明度
- 文件拖入时高亮（透明度 90%，边框高亮）但不改变尺寸
- 鼠标拖拽可移动位置
- 右键菜单：打开规则管理 / 打开设置 / 退出
- 位置信息保存在 settings.json，下次启动恢复

### 3.2 右键菜单

- 安装程序时注册 `HKEY_CLASSES_ROOT\*\shell\FileOrganizer`
- 选中任意文件/文件夹右键 → "整理(File Organizer)"
- 通过参数传递文件路径启动程序
- 设置界面提供一键注册/卸载

### 3.3 整理弹窗

```
┌──────────────────────────────────────────┐
│  整理文件                                 │
├──────────────────────────────────────────┤
│  文件: 截图_2026-05-04.png               │
│  文件名: [截图_2026-05-04.png__________]  │
│                                         │
│  目标标签:  (单选)                       │
│  ○ 图片  → D:\Pictures                  │
│  ○ 文档  → D:\Documents                 │
│  ○ 下载  → D:\Downloads                 │
│                                          │
│  冲突时: [弹窗选择          ▼]          │
│                                         │
│  [ 移  动 ]               [ 取  消 ]    │
└──────────────────────────────────────────┘
```

- 多文件同时拖入时：展示文件列表，逐一编辑或批量选标签
- 文件名编辑框支持键盘操作
- 标签选择后确认 → 执行移动
- "移动"按钮在未选择标签时禁用

### 3.4 规则管理窗口

- 顶部表格：标签名、目标路径、操作（编辑/删除）
- 底部：[添加规则] [导入] [导出] 按钮
- 添加/编辑弹窗：标签名（必填）、目标路径（支持浏览文件夹对话框）
- 删除前确认弹窗
- 路径支持环境变量（如 `%USERPROFILE%\Downloads`）

### 3.5 设置窗口

- 开机自启：写注册表 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`
- 默认冲突处理：下拉选择（弹窗/自动加序号/覆盖/跳过）
- 右键菜单启用/禁用
- 移动后删除空源文件夹

## 四、数据模型

### rules.json

```json
[
  { "id": "guid-1", "name": "图片", "path": "D:\\Pictures", "createdAt": "2026-05-04T00:00:00Z" },
  { "id": "guid-2", "name": "文档", "path": "D:\\Documents", "createdAt": "2026-05-04T00:00:00Z" }
]
```

### settings.json

```json
{
  "startWithWindows": false,
  "minimizeToTray": true,
  "contextMenuEnabled": true,
  "defaultConflictAction": "prompt",
  "deleteEmptySourceDir": false,
  "floatingWindowX": 100,
  "floatingWindowY": 100
}
```

### ConflictAction 枚举

| 值 | 行为 |
|------|------|
| `prompt` | 弹窗让用户选择 |
| `autoRename` | 自动加序号（文件 (1).ext） |
| `overwrite` | 覆盖 |
| `skip` | 跳过不处理 |

## 五、核心流程

### 正常流程

1. 用户将文件拖到悬浮窗（或右键 → 整理）
2. 程序解析文件路径
3. 弹出整理弹窗，填充文件名，加载标签列表
4. 用户选择标签，可选编辑文件名
5. 点击移动
6. 文件移动器：检查目标目录（不存在则创建）→ 检查冲突 → 移动文件
7. 移动完成 → 弹窗关闭（或提示成功）
8. 若开启"删除空源文件夹"，检查源目录是否为空

### 冲突流程

1. 目标文件已存在
2. 读取 `defaultConflictAction`
3. 若为 `prompt` → 弹出冲突选择对话框
4. 用户选择（覆盖/加序号/跳过/全部...）
5. 执行对应操作

### 多文件流程

1. 用户拖入 N 个文件/文件夹
2. 整理弹窗展示完整文件列表
3. 每个文件名可独立编辑
4. 选择一个标签统一移动到同一个目标目录
5. 按列表顺序逐个处理，冲突按默认策略

## 六、边界情况处理

| 场景 | 处理 |
|------|------|
| 目标路径不存在 | 自动创建完整目录树 |
| 文件被其他进程占用 | 捕获 IOException，弹窗提示，跳过该文件 |
| 目标路径是网络路径 | 支持 UNC（`\\server\share`） |
| 配置 JSON 解析失败 | 弹窗报错，重置为默认配置 |
| 悬浮窗被拖出屏幕 | 限制边界 |
| 权限不足 | 以管理员身份运行提示 |
| 双击悬浮窗 | 放大/缩小（可选） |
| 右键从文件夹管理器触发 | 传递多个路径参数 |
| 程序已运行 | 激活已有窗口，传递文件路径 |

## 七、开发计划（Phase）

### Phase 1 — 最小可用版

- 创建 C# .NET 8 WinForms 项目
- 悬浮窗（拖放 + 拖拽移动 + 右键菜单）
- 整理弹窗（文件名编辑 + 标签选择 + 移动执行）
- ConfigManager（JSON 读写 + 内存缓存）
- FileMover（移动 + 重命名 + 冲突处理）
- 单实例守卫

**产出：可拖放整理文件的最小版本**

### Phase 2 — 可配置完整版

- 规则管理窗口（标签 CRUD + 路径浏览）
- 设置窗口（开机自启 + 默认冲突策略 + 右键菜单开关）
- 系统托盘（最小化 + 悬浮窗显示/隐藏 + 设置入口）

**产出：用户可自行配置规则和偏好的完整版本**

### Phase 3 — 完善版

- 右键菜单注册/卸载（注册表操作 + UAC 提权）
- 多文件整理优化（批量处理进度）
- 导入/导出配置
- 错误日志（简单 log 文件）

**产出：可日常使用的完善产品**
